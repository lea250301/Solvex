# Izbira frontend tehnologij

## Kontekst in problem
Sistem Solvex potrebuje uporabniški vmesnik, prek katerega lahko lastniki sončnih elektrarn prijavljajo napake in naročajo redne preglede, 
serviserji pregledujejo svoje naloge, vodja servisa pa upravlja servisne aktivnosti. Odločiti se je treba, katere tehnologije uporabiti za razvoj 
frontenda, da bo uporabniški vmesnik pregleden, odziven in enostaven za vzdrževanje ter nadaljnji razvoj.

## Možne opcije

* HTML, CSS in JavaScript, brez uporabe ogrodja
* React, Vite in TypeScript.
* Angular in TypeScript.
* Vue.js in JavaScript.

## Izbrana opcija
Izbrana odločitev: "React, Vite in TypeScript", ker React omogoča izdelavo uporabniškega vmesnika iz ponovno uporabljivih komponent, kar olajša razvoj 
različnih pogledov za posamezne vrste uporabnikov. Vite omogoča hiter razvoj in pripravo aplikacije za objavo, TypeScript pa z uporabo tipov pomaga 
pri odkrivanju napak med razvojem in izboljšuje preglednost kode.

### Posledice

* Slabo, ker je za uporabo izbranih tehnologij potrebno spoznati dodatna orodja in njihove načine delovanja.
* Dobro, ker je mogoče uporabniški vmesnik razdeliti na manjše, ponovno uporabljive komponente.
* Dobro, ker TypeScript omogoča zgodnejše odkrivanje določenih napak in izboljša vzdrževanje kode.
